# Travel v2 Alpha Event Pair Outline

Status: active event design contract.

This document outlines the two Travel v2 alpha events required by `docs/TRAVEL_V2_ALPHA_GOAL.md`. It is not runtime data yet. It exists so implementation slices can build concrete mechanics instead of inventing abstract systems without table context.

Use this with:

- `docs/ARCFLIGHT_ALPHA_PILLAR_ROADMAP.md` for project sequencing.
- `docs/TRAVEL_V2_ALPHA_GOAL.md` for the locked Travel Alpha target.
- `docs/TRAVEL_V2_ALPHA_TODO.md` for the implementation sequence.
- `docs/TRAVEL_V2_OPEN_ISSUES.md` for `TV2-###` tracker IDs.

## Event pair purpose

Travel Alpha must prove two different kinds of Travel v2 play:

1. **The Lantern in the Static** proves occult pressure, hidden hazards, Lifeveil/Morale/Strain, command echoes, and mystery-driven decisions.
2. **Shattered Chain Drift** proves physical voidfaring pressure, Hull/Strain/Supplies/Cargo, environmental hazards, salvage, route clues, and ship-scar consequences.

Together, the pair should exercise:

- Event setup and visible stakes.
- Five core stations.
- Station order before Round 1.
- Action lock-in.
- Risk bids `+2`, `+5`, `+8`.
- Focus as pre-roll `2d20 keep highest` with backlash.
- Shared Momentum.
- Inter-Station Help.
- Main evolving hazard.
- Secondary hazards.
- Six hazard forms.
- Dynamic between-round vignettes.
- Mechanical callouts below prose.
- Final decision point.
- Rewards, clues, consequences, scars, and follow-ups.
- Explicit GM Apply to Ship.
- Audit/history record.
- No silent mutation.
- No player leaks.

## Shared alpha event assumptions

These assumptions apply to both events unless overridden later by an intentional docs PR.

### Round count

- Minimum: 3 rounds.
- Maximum: 12 rounds.
- Alpha events should use 3 rounds each unless a specific test requires more.

### Core stations

Every alpha event uses all five core stations:

- Captain.
- Navigator.
- Engineer / Arkengineer.
- Veilwarden.
- Watchmaster.

Some rounds may emphasize certain stations, but no core station disappears.

### Station order

- Players choose station order before Round 1 begins.
- Captain has final say if the table cannot agree, as guidance text.
- GM can drag/reorder, lock, and unlock.
- The order remains fixed for the whole event unless the GM unlocks it.
- Earlier stations can create Inter-Station Help for later stations in the same round.

### Risk bids

Risk bid tiers are fixed:

| Tier | Meaning |
| --- | --- |
| `+2` | A modest push with real risk. |
| `+5` | A dangerous commitment. |
| `+8` | A desperate overreach that must never be harmless on failure. |

Risk bids:

- Are chosen before rolling.
- Are chosen before consequences are known.
- Cost nothing up front.
- Increase danger through pressure, hazard escalation, consequence candidates, station complications, reward changes, or ship scar candidates.
- Must be event-authored and station-flavored.

### Focus

Focus is not a post-failure reroll.

- Declared before rolling.
- Roll `2d20`, keep the better result.
- Once per event per assigned station/player unless later rules change this.
- Only available on actions that allow Focus.
- Failure creates backlash.
- Critical failure creates severe backlash.
- Focus can interact with risk bids but must not make them safe.

### Momentum

Momentum is shared crew advantage.

- Visible to players.
- Tied to the ship actor where practical.
- Can be awarded by GM for clever play or strong roleplay.
- Resets at event end.
- Alpha spends should include: reveal a clearer hidden hazard tell, suppress a hazard effect, improve a benefit, or reduce/prevent pressure where allowed.

### Dynamic vignette assembly

Between-round vignettes should be assembled from actual results.

Preferred ingredients:

1. Base transition.
2. Best station result.
3. Worst station result.
4. Major hazard movement.
5. Hidden hazard tell.
6. Resource or pressure change.
7. Next-round hook.

The GM can edit the official vignette before showing it. Mechanical callouts appear immediately below prose.

## Event 1: The Lantern in the Static

### One-line pitch

A lone lantern burns in a cloud of silver static, repeating commands in the crew's own voices before anyone speaks them; the crew must decide whether to rescue the true flame, cut free, or burn hard and abandon it before the static learns how to command the ship.

### Primary test profile

| Area | Target |
| --- | --- |
| Genre | Occult void mystery / survival crossing. |
| Primary resources | Lifeveil, Morale, Strain. |
| Secondary resources | Possible Supplies or Cargo only if authored by consequence. |
| Main pressure | The ship's voices, commands, and protective breath are being imitated. |
| Main hazard style | Hidden evolving occult hazard. |
| Player feeling | Creepy command confusion, rescue temptation, disciplined table choice. |
| Final decision | Rescue, sever/release, or abandon/burn hard. |

### What Lantern must prove

- Hidden hazards can have tells before reveal.
- Momentum can reveal a clearer hidden hazard tell without exposing all GM notes.
- Lifeveil/Morale/Strain pressure can change through reviewed paths.
- Risk bids can create occult backlash.
- Focus can help but can worsen the static if it fails.
- Inter-Station Help can protect later stations from false commands or borrowed breath.
- Dynamic vignettes can include command echoes, copied voices, and hidden-hazard movement.
- Final outcome can produce reward, consequence, follow-up, or ship scar candidates without automatic mutation.

### Event setup stakes

Player-visible setup should include:

- A lantern burns inside silver static ahead.
- The static repeats fragments of shipboard orders in familiar voices.
- The Lifeveil, crew morale, and arkengine rhythm are threatened.
- Something inside the lantern may be trapped.
- Something around the lantern may be baiting the crew.
- The crew must keep command of their own ship long enough to choose what to do.

GM-only setup should include:

- The main hazard is not the lantern itself; it is the thing using the lantern as bait.
- The static learns from answered voices, risk bids, failed Focus, and uncontrolled command echoes.
- The true flame can become a reward or route clue if rescued cleanly.
- Failed final choices can create an occult ship scar candidate.

### Round structure

#### Round 1 — The Lantern Answers Before You Speak

Core question: can the crew approach without teaching the static how command works aboard the ship?

Round stakes:

- The static repeats orders one heartbeat before anyone speaks them.
- The route bends toward the lantern.
- The arkengine begins echoing its own pulse.
- The Lifeveil carries syllables from outside the hull.

Expected tests:

- Visible stakes before first roll.
- Station action lock-in.
- Low-to-medium risk bids.
- First hidden hazard tell.
- First Inter-Station Help creation.

Possible round result hooks:

- Strong result: the ship keeps its words its own; the true flame briefly sounds frightened rather than hungry.
- Mixed result: the static learns a little of the crew's rhythm; a few ward-lamps burn blue.
- Bad result: someone answers; the static steals a command and sends it running deck to deck.

#### Round 2 — The Voices Know the Crew

Core question: can the crew separate useful truth from emotional bait?

Round stakes:

- Dead crew, old captains, family, creditors, saints, and false memories speak through the static.
- Some warnings are accurate.
- Some pleas are bait.
- The thing behind the lantern moves only when attention turns toward the voices.

Expected tests:

- Hidden hazard tell becomes clearer.
- Momentum reveal can name or describe part of the hazard.
- Help from Round 1 does not carry unless authored to do so.
- Medium-to-high risk bids should feel tempting.
- Focus failure can produce meaningful backlash.

Possible round result hooks:

- Strong result: the crew learns a true bearing without surrendering trust.
- Mixed result: the lantern learns the crew while the crew learns the path.
- Bad result: the static gets inside the arkengine rhythm or Lifeveil grief response.

#### Round 3 — The Thing Wearing the Lantern

Core question: what does the crew choose when the real predator is revealed?

Round stakes:

- The lantern cracks.
- The predator unfolds around it as echo, hunger, and wings of static.
- The crew can rescue the true flame, sever/release it, or burn hard and abandon it.
- The final order must be clear enough that the static cannot twist it.

Expected tests:

- Final decision point.
- High-risk bids.
- Ship scar candidate on severe failure.
- End-of-Event Resolution.
- Explicit GM Apply to Ship.
- Audit/history record.

Possible final choices:

1. **Rescue the True Flame** — highest reward, highest occult risk.
2. **Cut Free / Release Cleanly** — safer, lower reward, fewer hooks.
3. **Burn Hard and Abandon It** — fastest escape, Strain risk, possible Morale or occult consequence.

### Lantern main evolving hazard

**The Static Around the Lantern**

Type: hidden main evolving hazard.

Progression:

1. Tell: commands arrive before anyone speaks.
2. Tell: voices become familiar and emotionally specific.
3. Partial reveal: the lantern is worn by something else.
4. Full reveal: the static predator tries to claim the ship's command pattern and Lifeveil.

Possible triggers:

- Answering voices without control.
- Failed risk bid.
- Failed Focus.
- Ignoring Watchmaster tells.
- Letting arkengine or Lifeveil accept borrowed commands.
- Final-round hesitation.

Possible effects:

- Lifeveil pressure.
- Morale pressure.
- Strain pressure.
- Station modifier to Captain or Veilwarden.
- Temporary restriction on actions that rely on spoken command.
- Consequence candidate: Static Fingerprints.
- Ship scar candidate: Echoes in the Rigging.

### Lantern secondary hazards

These hazards do not all need to appear in one run. They form the event-tagged pool.

| Hazard | Form | Player-visible reveal |
| --- | --- | --- |
| False Command Echo | Station Modifier / Station Lockout | A familiar command arrives too early and makes one station's chosen action harder or temporarily unsafe. |
| Borrowed Breath | Pressure Cascade | The Lifeveil carries a voice from outside the ship, increasing Lifeveil pressure if not answered. |
| Arkengine Mirror-Pulse | Countdown | The arkengine echoes itself; if the countdown completes, Strain spikes or a risk bid backlash worsens. |
| Static Hands | Response Action | Silver static crawls along rigging or wards; stations can suppress or redirect it. |
| Dead Voice in the Rigging | Consequence Handoff | If unresolved, becomes a GM-reviewed consequence or ship scar candidate. |
| Lantern Parasite | Main Hazard Escalation | The thing wearing the lantern reveals itself and turns previous answers into final-round pressure. |

### Lantern station action themes

#### Captain

Focus: discipline, mercy, final command.

Possible actions:

- Set shipwide silence protocol.
- Permit one controlled voice exchange.
- Issue the final rescue/severance/escape order.

Risk bid flavor:

- `+2` Press the Crew.
- `+5` Hard Command.
- `+8` No One Breaks.

Focus example:

- Command Focus: declare before a decisive command roll; if failed, the static copies the command tone and creates backlash.

Help example:

- Captain can create **Disciplined Deck**, letting a later station ignore or reduce False Command Echo.

#### Navigator

Focus: route truth, false bearings, final escape line.

Possible actions:

- Skirt the static.
- Test a voice-given bearing.
- Plot the final line through collapsing static.

Risk bid flavor:

- `+2` Cut the Angle.
- `+5` Thread the Needle.
- `+8` Blind Through the Black.

Focus example:

- Bearing Focus: roll `2d20` to commit to a true bearing; failure may make the route remember the wrong answer.

Help example:

- Navigator can create **True Bearing Window**, giving a later Engineer or Captain a clean timing cue.

#### Engineer / Arkengineer

Focus: arkengine rhythm, resonance, final burn.

Possible actions:

- Break command resonance.
- Partition engine memory.
- Surge the arkengine without carrying the parasite.

Risk bid flavor:

- `+2` Hot Tune.
- `+5` Dangerous Burn.
- `+8` Arkengine Overload.

Focus example:

- Arkengine Focus: roll `2d20` to time a clean resonance break; failure may create Mirror-Pulse backlash.

Help example:

- Engineer can create **Damped Pulse**, reducing Strain pressure or helping Navigator read a cleaner route.

#### Veilwarden

Focus: Lifeveil boundary, breath, grief, ward-lamps.

Possible actions:

- Seal ward-lamps.
- Reject borrowed grief.
- Harden the Lifeveil before final contact.

Risk bid flavor:

- `+2` Thin the Veil.
- `+5` Borrow Breath.
- `+8` Open the Wards.

Focus example:

- Ward Focus: roll `2d20` to lock the Lifeveil against borrowed voices; failure may create Borrowed Breath backlash.

Help example:

- Veilwarden can create **Clean Breath**, letting a later station resist Lifeveil or Morale pressure.

#### Watchmaster

Focus: tells, timing, predator movement.

Possible actions:

- Separate true warnings from bait.
- Watch the light's edge.
- Call the true final moment.

Risk bid flavor:

- `+2` Call the Pattern.
- `+5` Stand Exposed.
- `+8` Eyes on the Impossible.

Focus example:

- Vigil Focus: roll `2d20` to identify the hidden hazard's real timing; failure may expose the Watchmaster to a direct tell-backlash.

Help example:

- Watchmaster can create **False Timing Exposed**, giving a later station automatic protection against one false urgency or station modifier.

### Lantern Momentum spends

Possible alpha spends:

- Reveal a clearer hidden hazard tell: name the predator as a parasite or reveal that the lantern is being worn.
- Suppress one False Command Echo.
- Improve an Inter-Station Help benefit.
- Reduce Lifeveil or Morale pressure from a single reviewed source.
- Upgrade a final choice reward if the crew earned enough advantage.

### Lantern rewards and consequences

Possible rewards:

- True Lantern Flame as a narrative boon, not automatic item creation.
- Clear bearing out of the dead stretch.
- Route clue tied to occult void hazards.
- Crew confidence against command-echo hazards.

Possible consequence candidates:

- Static Fingerprints: a copied voice, marked wake, or blue ward-lamp.
- Copied Command: an order may return later at the wrong time.
- Borrowed Grief: Morale pressure or roleplay follow-up.

Possible ship scar candidates:

- Echoes in the Rigging.
- Blue Ward-Lamp.
- Mirror-Pulse in the Arkengine.

Apply-to-ship candidates:

- Approved resource deltas.
- Approved ship scar.
- Approved route clue.
- Approved follow-up.
- Completed event record.

## Event 2: Shattered Chain Drift

### One-line pitch

The ship drops into the shadow of a broken Ayerstone-scale chain-field where shattered adamantite links, wreckage, cargo pods, and gravity eddies drift across the route; the crew must choose whether to ride the chainwake, salvage the wreckage, or cut through before the drift grinds the hull open.

### Primary test profile

| Area | Target |
| --- | --- |
| Genre | Physical voidfaring crisis / salvage hazard. |
| Primary resources | Hull, Strain, Supplies, Cargo. |
| Secondary resources | Morale if crew panic or lose salvage. |
| Main pressure | The ship is being dragged through broken chain debris and unstable gravity. |
| Main hazard style | Visible evolving environmental hazard. |
| Player feeling | Tactical, physical, practical, ship-endangering. |
| Final decision | Salvage, safe route, or hard cut through the drift. |

### What Shattered Chain Drift must prove

- Visible environmental hazards can drive gameplay without mystery structure.
- Hull/Supplies/Cargo pressure matter alongside Strain.
- Risk bids can create direct ship complications.
- Inter-Station Help can create physical openings, bracing, cover, and timing windows.
- Focus can help with dangerous physical maneuvers but worsen damage if it fails.
- Rewards can include salvage and route clues.
- Unresolved hazards can become ship scar candidates.
- End-of-event apply can attach approved salvage/route clue/scar records without automatic item creation.

### Event setup stakes

Player-visible setup should include:

- The route crosses a shattered chain-field.
- Broken links and wreckage are drifting across the path.
- Gravity eddies pull the ship toward a grinding debris lane.
- Cargo pods and salvage glimmer inside the hazard.
- The ship can take a safer line, attempt salvage, or cut through hard.
- Hull, Strain, Supplies, and Cargo are threatened.

GM-only setup should include:

- The chain-field hides a route clue in the wreckage.
- Salvage is possible but increases exposure.
- The main hazard escalates from debris impact to chainwake shear to anchor-drag crush.
- Failed high-risk choices may create a ship scar candidate.

### Round structure

#### Round 1 — The Broken Links Begin to Turn

Core question: can the crew enter the chain-field without losing control of the route?

Round stakes:

- Shattered chain links rotate slowly across the approach.
- Gravity eddies pull small debris into the ship's path.
- Loose cargo pods flash in the wreckage.
- The helm can choose a safer wide line, a salvage line, or a hard cut through.

Expected tests:

- Visible stakes.
- Physical hazard display.
- Station order importance.
- Low-to-medium risk bids.
- First salvage temptation.
- First Hull/Strain pressure hook.

Possible round result hooks:

- Strong result: the crew reads the chainwake and finds a clean angle.
- Mixed result: the ship gets inside the drift, but loose debris clips the hull or cargo rigging.
- Bad result: the ship is pulled toward the grinding lane; pressure begins building immediately.

#### Round 2 — The Wreckage Offers Teeth and Treasure

Core question: does the crew risk salvage or focus entirely on survival?

Round stakes:

- Wreckage opens like a field of blades.
- Cargo pods, broken armor plates, and a route-marker fragment drift in reach.
- Chainwake shear begins dragging the ship sideways.
- The easiest salvage line is also the most dangerous line.

Expected tests:

- Inter-Station Help becomes tactically important.
- Medium-to-high risk bids.
- Visible secondary hazard activation.
- Supplies/Cargo pressure or reward tradeoff.
- Response action hazard.

Possible round result hooks:

- Strong result: the ship secures salvage or a route clue while maintaining control.
- Mixed result: salvage is possible, but something must be abandoned, spent, or damaged.
- Bad result: the drift bites into hull or cargo, creating a consequence or scar candidate.

#### Round 3 — Anchor-Drag Crush

Core question: does the crew commit to salvage, safe escape, or a brutal hard cut through the chainwake?

Round stakes:

- A massive broken anchor-link turns end over end through the drift.
- The chainwake tightens like a current around the ship.
- Salvage and route clues are nearly out of reach.
- The final maneuver determines whether the ship escapes cleanly, escapes damaged, or carries a lasting scar.

Expected tests:

- Final decision point.
- `+8` risk bid danger.
- Ship scar candidate.
- Explicit reward/consequence selection.
- End-of-Event Resolution.
- Explicit GM Apply to Ship.

Possible final choices:

1. **Take the Safe Line** — lower reward, lower risk, preserves ship.
2. **Grab the Salvage** — better reward, Cargo/Supplies opportunity, higher Hull/Strain risk.
3. **Hard Cut Through the Chainwake** — fastest route/clue chance, serious ship scar risk on failure.

### Shattered Chain Drift main evolving hazard

**The Grinding Chainwake**

Type: visible main evolving environmental hazard.

Progression:

1. Broken links rotate across the route.
2. Debris lanes converge with the ship's path.
3. Chainwake shear pulls the ship sideways.
4. Anchor-drag crush threatens hull, cargo, and arkengine strain.

Possible triggers:

- Choosing salvage line.
- Failed risk bid.
- Failed Focus.
- Ignoring Watchmaster or Navigator warnings.
- Overburning the arkengine without bracing.
- Final-round hard cut failure.

Possible effects:

- Hull pressure.
- Strain pressure.
- Supplies loss.
- Cargo loss or cargo complication.
- Station modifier to Navigator or Engineer.
- Temporary lockout of a salvage option.
- Consequence candidate: Damaged Cargo Rigging.
- Ship scar candidate: Chain-Scored Hull.

These hazards form the event-tagged pool.

Risk bids are the first deep mechanical system to implement after the event pair is outlined because they touch station actions, consequences, hazards, Focus, Momentum, and rewards.
