# Codex Closeout Notes

Status: historical implementation notes.

Files in this directory are PR closeout notes, smoke coverage notes, generated prompts, and implementation-history records. They are useful for understanding why a past slice exists, what it validated, and what it intentionally did not change.

They are not the current Arcflight roadmap, TODO list, project bible, or Travel v2 source of truth.

Use the current docs in this order:

1. `../DOCS-INDEX.md` — documentation entry point and source-of-truth order.
2. `../ARCFLIGHT-BIBLE.md` — canonical project design, locked rules, and system overview.
3. `../ROADMAP.md` — canonical development roadmap and phase order.
4. `../TODO.md` — canonical active task list.
5. `../TRAVEL-V2.md` — canonical Travel v2 design and implementation reference.
6. Files in this directory — historical closeout/reference notes.

When a historical closeout note appears to conflict with a current source-of-truth doc, treat the current source-of-truth doc as authoritative unless a later docs PR intentionally changes that decision.

Do not delete these files just because the work is complete. They preserve implementation context and smoke-test history.
