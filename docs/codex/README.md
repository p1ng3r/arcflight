# Codex Closeout Notes

Status: historical implementation notes.

Files in this directory are PR closeout notes, smoke coverage notes, and implementation-history records. They are useful for understanding why a past slice exists, what it validated, and what it intentionally did not change.

They are not the current Arcflight roadmap and should not override the active roadmap documents.

Use the current docs in this order:

1. `../ARCFLIGHT_ALPHA_PILLAR_ROADMAP.md` — top-level project sequence.
2. `../TRAVEL_V2_ALPHA_GOAL.md` — locked Travel Alpha gameplay goal.
3. `../TRAVEL_V2_ALPHA_TODO.md` — active Travel Alpha implementation checklist.
4. `../TRAVEL_V2_OPEN_ISSUES.md` — numbered Travel v2 implementation tracker.
5. Files in this directory — historical closeout/reference notes.

When a historical closeout note appears to conflict with a current roadmap or alpha-goal doc, treat the current roadmap or alpha-goal doc as authoritative unless a later docs PR intentionally changes that decision.

Do not delete these files just because the work is complete. They preserve implementation context and smoke-test history.
