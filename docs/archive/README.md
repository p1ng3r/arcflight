# Docs Archive

This folder is for superseded, historical, or reference-only documentation.

Archived documents may still be useful, but they are not source-of-truth unless a current source-of-truth doc explicitly points to them.

## Current source-of-truth docs

Use these first:

- `docs/DOCS-INDEX.md`
- `docs/ARCFLIGHT-BIBLE.md`
- `docs/ROADMAP.md`
- `docs/TODO.md`
- `docs/TRAVEL-V2.md`
- `docs/ARCHITECTURE.md`
- `docs/DATA-MODEL.md`
- `docs/TESTING.md`
- `docs/GLOSSARY.md`
- `docs/DECISIONS.md`

## Archive rules

When moving a file into this folder, add a note at the top of the archived file:

```md
# Archived / Superseded

This document is historical reference only.

Current source:
- docs/DOCS-INDEX.md
- docs/ROADMAP.md
- docs/TODO.md
```

Do not delete old planning material until it has been reviewed for useful context.

## What belongs here

- superseded roadmaps
- old implementation plans
- old Codex prompts that no longer define active work
- closeout notes that are useful history but not current direction
- phase plans that have been replaced by the current roadmap
