Status: historical task prompts and implementation notes.

Files in this directory are task prompts, phase notes, and implementation plans used during earlier Travel v2 development. They may explain why a slice was shaped a certain way, but they are not the current roadmap, TODO list, or Travel v2 source of truth.

Use the current docs first:

1. `../DOCS-INDEX.md` — documentation entry point and source-of-truth order.
2. `../ARCFLIGHT-BIBLE.md` — canonical project design, locked rules, and system overview.
3. `../ROADMAP.md` — canonical development roadmap and phase order.
4. `../TODO.md` — canonical active task list.
5. `../TRAVEL-V2.md` — canonical Travel v2 design and implementation reference.

When a Codex task file conflicts with the current docs spine, the current docs spine wins unless a later docs PR intentionally changes the source of truth.

Do not delete task files just because the work is complete. They preserve implementation context until a later archive/delete pass intentionally removes them.
